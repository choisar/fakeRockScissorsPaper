# 자기소개서·포트폴리오를 위한 개선 계획

## 1. 프로젝트의 중심 질문

빠더너스의 [이 영상](https://youtu.be/YJckrnOUaoM)에서 비용 부담자를 가위바위보로 정하며 일부가 같은 손을 내기로 약속하는 장면을 보고 시작했다. 처음에는 생존 확률에 큰 차이가 없으리라 예상했다. 링크와 장면 설명은 작성자 제공이며 영상의 세부 규칙은 별도 검증하지 않았다.

주 질문: 일부 참가자가 같은 손을 내면, 담합자 한 명의 생존 확률은 비담합자 한 명보다 얼마나 달라지는가? 그 차이는 어떤 조건에서, 왜 발생하는가?

주 지표는 실험군 안에서의 집단별 개인 평균 생존율 차이 Δ = p_C - p_N이다. 전원 무작위 선택의 생존율 (n-k)/n과의 비교는 보조 지표로 둔다. 집단의 생존 인원 합계와 개인 생존 확률을 구분한다.

## 2. 현재 상태와 보완점

- 참가자 4·6명, 담합자 2·3·4명, 술래 1·2명의 유효한 10개 조건과 조건별 실험군·대조군 각 10만 회 결과가 있다.
- project.md에는 1,000회 × 1,000블록으로 적혀 있지만 실제 simulate.py는 10만 회를 실행하므로 문서와 구현을 맞춰야 한다.
- simulate.py가 출력 문자열을 다시 파싱해 술래 명단을 얻는다. 게임 결과를 구조화해 직접 반환하도록 바꾼다.
- 난수 시드와 실행 환경 기록이 없어 기존 결과를 그대로 재현하기 어렵다. 기존 결과는 초기 탐색 결과로 보존한다.
- 집단 신뢰구간에서 같은 게임의 참가자를 독립 표본처럼 처리한다. 게임 단위로 분석을 수정해야 한다.
- 생존 여부 0/1의 중앙값은 비교에 도움이 적다. 핵심 화면은 생존율, 차이(%p), 신뢰구간, 이론값을 중심으로 구성한다.
- 현재 데이터는 관측된 차이를 보여주지만 발생 원인에 대한 분석과 정확 확률 계산은 없다.

## 3. 단계별 작업

### 1단계: 질문·가정·규칙 확정

1. 연구 질문, 처음의 예상, 주 지표와 보조 지표를 project.md에 명시한다.
2. 비담합자의 매 투구 독립·균등 선택, 담합자의 고정 손, 담합자만 남았을 때 무작위 전환을 명시한다.
3. 패배 인원이 정원보다 많거나 적을 때의 선정 과정을 작은 사례와 함께 설명한다.
4. 영상은 질문의 계기이고 실험은 별도로 정의한 규칙의 모델임을 구분한다. 영상과 규칙이 같다는 주장은 확인 전에는 하지 않는다.

완료 기준: 제3자가 문서만 읽고 같은 게임 규칙과 비교 질문을 구현할 수 있다.

### 2단계: 재현 가능한 실험 기반

1. 게임 엔진, 실험 실행, 통계 분석, 리포트 생성을 분리한다.
2. 게임은 최종 술래 명단을 반환하고, 선택적으로 라운드별 참가자·손·승패·다음 참가자 집합을 기록한다.
3. 실행 옵션으로 참가자 수, 담합자 수, 술래 수, 시행 수, 시드, 출력 경로를 받는다.
4. 시드·설정·실행 시각·Python 및 의존성 버전을 결과에 기록하고 의존성 설치 방법을 제공한다.
5. 게임별 두 집단의 생존 인원과 차이를 저장해 분석을 다시 할 수 있게 한다. 전체 투구 로그는 설명용 소수 게임에만 저장한다.
6. 기존 결과는 덮어쓰지 않고 초기 결과와 개선 후 결과를 구분한다.

검증: 술래 정원·중복 없음·입력 범위·정원 초과/미달 분기·담합자만 남는 경우·동일 시드 재현을 확인한다. 무작위 대조군은 이론 생존율과의 일치 여부를 오차 범위와 함께 확인한다.

완료 기준: 명시된 한 명령과 시드로 같은 결과를 재생성할 수 있다.

### 3단계: 질문에 맞는 통계 분석

1. 게임마다 d_g = (담합 생존 인원 / 담합 인원) - (비담합 생존 인원 / 비담합 인원)을 계산한다.
2. 독립 게임들의 d_g 평균으로 Δ를 추정하고 게임 단위 표준오차로 95% 신뢰구간을 계산한다. 개별 참가자의 관측치를 별개의 독립 표본으로 합치지 않는다.
3. 생존율 차이를 %p로 표시하고, 통계적 차이와 실제 차이의 크기를 함께 설명한다.
4. 여러 조건에 대해 유의성을 판단한다면 다중 비교를 고려한다. 신뢰구간에 0이 포함된다는 이유만으로 동등하다고 결론짓지 않는다.
5. 기존 10개 조건을 고정된 시드로 다시 실행하고 서로 다른 시드에서 결과가 안정적인지 확인한다.
6. 집단 내 참가자가 대칭적인 규칙이라는 점과 개별 생존율도 점검해 집단 평균의 의미를 설명한다.

완료 기준: 각 조건에서 p_C, p_N, Δ, Δ의 신뢰구간, 시행 수와 시드를 한 표에서 확인할 수 있다.

### 4단계: 왜 차이가 생기는지 설명

1. 대표 조건 3개를 선정한다: 차이가 큰 조건, 차이가 작은 조건, 관측 차이가 거의 없는 조건.
2. 작은 참가자 수부터 가능한 손 조합과 확률을 열거한다.
3. 상태를 남은 담합자 수·비담합자 수·추가로 정할 술래 수로 표현하고, 승패 뒤의 상태 전이를 계산한다.
4. 무승부의 자기 반복 확률을 처리하고 종료 상태까지의 기대 술래 인원을 재귀·메모이제이션으로 계산한다. 기대 인원을 집단 인원으로 나누어 개인 확률을 얻는다.
5. 시뮬레이션의 판정 함수를 그대로 복사하지 않는 독립적인 작은 사례 검산을 마련하고, 정확 계산과 시뮬레이션의 일치 여부를 확인한다.
6. 담합으로 손 선택이 연결되면 집단이 함께 승패 분기로 이동한다는 관점에서 원인을 탐색한다. 유리함의 방향이나 조건은 계산 결과를 보고 결론짓는다.

완료 기준: 대표 조건의 정확 확률, 시뮬레이션 추정값, 분기 그림과 쉬운 설명이 함께 있다.

### 5단계: 포트폴리오 결과물

README 구성:
1. 영상에서 발견한 질문과 처음 예상
2. 실험 규칙과 가정
3. 실험군·대조군 및 지표 설계
4. 대표 결과와 정확 계산을 통한 원인 설명
5. 분석 방법을 개선한 이유와 검증
6. 한계·후속 질문·재현 명령

HTML 리포트 구성:
- 조건 선택과 집단별 개인 생존율
- Δ(%p)와 95% 신뢰구간, 정확 계산값
- 조건별 차이 비교 차트
- 대표 게임의 분기 설명
- 적용한 가정과 실행 정보

포트폴리오는 문제 발견 → 가설 → 모델링 → 실험 → 예상과 다른 관측 → 원인 분석 순서로 읽히게 한다. 직접 한 판단과 AI·도구의 도움은 실제 작업에 맞춰 구분한다. 실제 사람의 전략까지 일반화하지 않는다.

완료 기준: 처음 보는 사람이 몇 분 안에 질문·방법·결과·본인의 기여를 이해하고, 안내대로 실험을 재현할 수 있다.

### 6단계: 자기소개서 반영

- 800자 안에서 계기 → 질문과 초기 예상 → 본인의 검증 행동 → 대표 결과 → 배움 순으로 정리한다.
- 대표 결과는 주 질문에 맞는 담합자와 비담합자 사이의 개인 생존율 차이를 사용한다.
- 원인 규명과 통계 검증은 실제 완료한 범위만 쓴다.
- 최초 탐색과 후속 고도화를 구분하고, 처음부터 모든 분석을 한 것처럼 쓰지 않는다.
- 자기소개서에서 사용한 수치는 최종 결과 파일과 연결해 확인할 수 있게 한다.

## 4. 실행 우선순위와 범위
